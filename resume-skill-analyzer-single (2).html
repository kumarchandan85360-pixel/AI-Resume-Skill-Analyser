Method

How the analysis works

  1. Read the file

    PDF text is rebuilt line by line from its text positions. Word files are converted to plain text. Plain text is used as it is.

  2. Split into sections

    Lines like Education, Skills, Projects and Experience are found with heading patterns, so each line knows which section it sits in.

  3. Extract skills

    About 120 skills are matched with regular expressions over names and aliases. sklearn and scikit-learn both become Scikit-learn, and word boundaries stop Java matching inside JavaScript.

  4. Check the evidence

    A skill found in Projects, Experience or Achievements is demonstrated. A skill found only in Skills, Education or Certifications is listed.

  5. Match the role

    Required skills weigh 3, nice-to-have weigh 1.5. Demonstrated counts 1.0, listed counts 0.7, missing counts 0. Some requirements accept any one of a group, such as React, Angular or Vue.

    match = 100 × earned weight ÷ total weight

  6. Score and combine

    Twelve quality rules add up to 100. For a job description, word-count cosine similarity is also shown.

    overall = 0.5 × match + 0.3 × quality + 0.2 × evidence

About

About this project

Purpose

A resume skill analyzer built as a college project. It shows how text processing, pattern matching and similarity scoring can turn a resume into a skill profile.

Built with

  • HTML, CSS, JavaScript
  • Regular-expression skill extraction
  • Cosine similarity on word counts
  • pdf.js and mammoth.js for file reading

Limits

  • English resumes only
  • About 120 skills in the taxonomy, mostly tech roles
  • Scanned image PDFs have no text to read
  • Rule-based, so the same resume always gets the same score
